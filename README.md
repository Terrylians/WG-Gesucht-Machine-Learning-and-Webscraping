# WG-Gesucht-Machine-Learning-and-Webscraping
This project focuses on collecting housing data from WG-Gesucht using web scraping techniques and applying machine learning and SQL-based tools for analysis. The pipeline extracts rental listings in Hamburg, processes and categorizes the data, and applies ML models to uncover patterns, trends, and insights in the local housing market.

**Key Features:**

Automated web scraping of WG-Gesucht listings for Hamburg.
Simpler data storage and querying with SQL databases.
Machine Learning models for categorization, clustering, and trend analysis.
Tools for identifying housing availability, price ranges, and demand patterns.
Framework for extending the analysis to other cities in Germany.

**Use Cases:**

Understanding housing availability and pricing dynamics in Hamburg.
Categorizing listings (e.g., furnished vs. unfurnished, short-term vs. long-term).
Supporting students, professionals, and researchers with structured housing data.
